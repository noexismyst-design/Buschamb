# Buschamb
Proyecto de desarrollo web

Se uso la asistencia de inteligencia artificial para la estructuracion y optimizacion de propiedades en el archivo CSS, como tambien, fue en algunas vistas de los archivos html como el inicio de sesion y los registros de cada uno de los usuarios.

Permite ingresar datos y redirige a la vista de perfil.   RF-02 Registrar empleadorregistro_empleador.html   Formulario con datos de la empresa, tipo de organización y logotipo.   Redirige hacia perfil_empleador.html.   RF-03 Iniciar sesióninicio_sesion.html   Formulario de autenticación con campos obligatorios (required).   Formulario funcional navegable a perfil_estudiante.html.   RF-04 Consultar vacantesinicio.html   Tarjetas dinámicas Flexbox con vacantes (#celulares, #restaurante, #cafeteria).   Muestra imagen, empresa, puesto y botones de acción.   RF-05 Consultar y descargar perfilperfil_estudiante.html / perfil_empleador.html   Maquetación con .bloque_superior_perfil (foto + datos) y enlace <a download> para el CV.
